# Security policy

## Reporting a vulnerability

Please report security issues privately by email to **vtts.kuklys@gmail.com**. Don't open a
public GitHub issue for them.

Include:

- the DejaView version (`npm ls dejaview-mcp` or the version in your MCP config),
- what you did, what happened, and what you expected,
- a minimal input that reproduces it, if you have one.

You'll get a response within 7 days. Once a fix is ready, we'll agree on a disclosure
date with you and credit you in the release notes if you'd like.

## Supported versions

Only the latest published version receives security fixes.
